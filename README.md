# 取件助手

Android 取件码管理应用，支持短信识别、待取/已取管理、统计、本地备份与在线更新。支持 Android 8.0 及以上。

## 安装

在 [Releases](https://github.com/syczk301/pickup-assistant/releases/latest) 下载最新版 APK。

## 在线更新

应用内打开 设置 → 检查更新。版本文件地址：

`https://github.com/syczk301/pickup-assistant/releases/latest/download/update.json`

新版本下载后会校验文件大小、SHA-256、包名、版本和签名，再交给系统安装程序确认。应用记录保存在本机，更新保留已有数据。

本仓库托管安装包、更新版本文件和发布说明。
