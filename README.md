# 取件助手

Android 8.0 及以上的取件码管理应用。支持短信识别、粘贴提取、手动添加、记录管理、筛选搜索、统计、提醒和小组件。

当前版本：**0.2.1**。

[下载安装包](https://github.com/syczk301/pickup-assistant/releases/latest/download/pickup-assistant-0.2.1.apk) · [查看发布版本](https://github.com/syczk301/pickup-assistant/releases)

## 在线更新

在应用的“设置 → 应用更新 → 检查更新”中下载并安装更新。默认每天自动检查一次，可关闭或修改 HTTPS 更新地址。首次安装更新需要允许本应用安装应用，并由用户在安卓系统安装界面确认。

版本文件地址：https://github.com/syczk301/pickup-assistant/releases/latest/download/update.json

安装前检查文件大小、SHA-256、包名、版本和签名。同一签名升级保留本地取件记录。短信与记录在设备本地处理，联网仅用于更新检查和下载。

此仓库托管发布文件和说明；签名密钥留在本地。后续发布方式见 [在线更新说明](在线更新说明.md)，实际测试结果见 [在线更新验证](在线更新验证.md)。
